# 누니드 브랜딩 포트폴리오

와이어프레임은 포폴프로세스1·2·3을 참고하여 세로형 케이스 스터디로 수정했습니다. 기존 22개 주제 사이에 SWOT, UI 컴포넌트, 그리드 설명을 추가했습니다. 디자인 버전은 기존 22페이지 가로 판형입니다.

- 브랜딩 포폴 프로세스 와이어프레임.html: 수정한 회색조 세로형 와이어프레임
- 브랜딩 포폴 프로세스 와이어프레임.pdf: 수정본 PDF
- 브랜딩 포폴 프로세스 와이어프레임_전체보기.jpg: 수정본 세로 전체 미리보기
- 원본보관: 수정 전 와이어프레임 HTML

HTML은 인터넷 없이 열 수 있습니다. 상단 메뉴와 좌우 방향키로 이동할 수 있습니다. PDF 인쇄 시 배경 그래픽을 켜세요.

SWOT은 기존 브리프 해석에 따른 기획 가설입니다. 실제 조사나 성과 수치를 새로 만들지 않았습니다. 패키지·앱·화면·컴포넌트 규칙은 제안입니다. 역할·기여율·작업 기간은 입력이 필요합니다.

수정본 재생성: portfolio-review/revise_wireframe.py
수정본 PDF·미리보기 검증: portfolio-review/check_revised_wireframe.py
기존 build_portfolios.py는 최초 버전을 생성하므로 실행하면 수정본을 덮어씁니다.

와이어프레임 전체 25페이지는 각 1920×1080 고정 판형입니다. 브라우저에서는 창 너비에 맞춰 전체 페이지를 축소 표시하며, PDF는 동일한 16:9 판형으로 출력합니다.
