# 🎙️ 사용자 인터뷰 분석 스킬 (v1.0)

이 스킬은 **PDF 및 TXT 형식의 사용자 인터뷰 자료**를 분석하여 6대 분류 기준에 맞춰 정리하고, 분석 근거와 원문 위치가 명확히 연결된 **3대 표준 보고서**를 생성합니다.

---

## 📥 1. 입력 자료 형식 (Supported Inputs)
- **PDF 파일** (`.pdf`)
- **텍스트 파일** (`.txt`, `.md`)
- (인터뷰 녹취록, 1:1 대면 인터뷰 메모, 필기록 등)

---

## 🏷️ 2. 6대 분류 기준 (Classification Categories)

1. **🎯 요구사항 (Requirements)**: 사용자가 원하거나 달성하고자 하는 목표/필요 사항
2. **⚡ 불편한 점 (Pain Points)**: 기존 사용 시 느낀 문제점, 장애물, 이탈 요인
3. **🔄 사용 행동 (User Behaviors)**: 문제를 해결하기 위해 취하는 기존 습관 및 절차
4. **👍 긍정적인 의견 (Positive Feedback)**: 서비스/제품에 대한 호평 및 만족 요소
5. **💡 개선 아이디어 (Improvement Ideas)**: 사용자가 제안한 새로운 기능 및 변경안
6. **❓ 추가 조사 질문 (Follow-up Questions)**: 추가 검증이나 정량 조사가 필요한 항목

---

## 📤 3. 출력 결과물 (Output Deliverables)

분석이 완료되면 `output/` 디렉토리에 아래 3개 문서가 생성됩니다:

```
output/
├── 01-자료목록.md       # 입력된 PDF/TXT 인터뷰 파일 전체 메타데이터 목록
├── 02-분류결과.md       # 6대 카테고리별 정제 및 인용 분류 데이터
└── 03-분석보고서.md      # 핵심 인사이트 + 원출처 근거가 연결된 최종 종합 보고서
```

---

## ⚙️ 4. AI 작업 가이드라인 (Workflow Rules)

1. **원문 근거 연결 의무화**:
   - 분석 결과의 모든 핵심 인사이트에는 반드시 `[자료명, Line / Page]` 형태의 출처 근거를 표기합니다.
2. **사실(Fact)과 해석(Interpretation)의 분리**:
   - 사용자가 직접 한 말/사실은 `[Fact]`, AI가 추론한 시사점은 `[AI Interpretation]`으로 엄격히 구별합니다.
3. **점진적 확장 원칙 (Roadmap)**:
   - v1.0 버전(사용자 인터뷰 분석 - PDF/TXT)의 안정적 실행 검증 후, v2.0 단계에서 **경쟁사 분석, 시장 조사, 논문 분석** 스킬로 확장합니다.
