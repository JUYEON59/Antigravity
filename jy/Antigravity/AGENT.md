## 📋 2. 리서치 자료 처리 6대 규칙 (`명령어 규칙.txt`)

1. **`[리서치 결과]`라는 이름이 들어간 파일을 항상 기본 리서치 자료로 사용한다.**
2. 사용자가 **"리서치 자료 추가 입력"**이라고 명령하면 이후에 제공하는 파일, URL, 텍스트를 추가 자료로 인식한다.
3. 추가 자료는 기존 자료를 덮어쓰지 않고 기존 데이터셋에 누적/병합(Append & Merge)한다.
4. 기본 자료와 추가 자료의 출처를 구분해서 명확히 기록한다. (예: `[기본 자료: [리서치 결과]_hybrid_beauty_references_200.txt]` vs `[추가 자료: URL / 파일명]`)
5. 같은 홈페이지가 중복되면 하나로 묶되, 발견된 모든 출처 히스토리는 남긴다.
6. **분석할 때 기본 자료와 추가 자료를 함께 사용한다.**

## ⚙️ 3. 출력 파일 분할 & 포맷 6대 규칙

- **분석 결과는 모두 UTF-8 .txt 파일로 생성**
- **TXT 파일당 최대 100개**

- **홈페이지 하나를 분석 결과 1개로 계산**

- **한 홈페이지의 내용은 두 파일로 나누지 않음** (개별 홈페이지 완결성 보장)

## 🧠 5. 8단계 심층 분석 방법론

1. **홈페이지별 개별 분석**: 디자인, 화면 구성, 사용자 흐름, 문구/콘텐츠, 주요 기능, 장단점, 참고할 부분 7개 요목 추출
2. **비슷한 내용 묶기**: 공통 등장 요소를 하나의 그룹으로 테마화
3. **등장 횟수 & 비율 확인**: 발견 횟수 및 비율(%) 산출
4. **패턴 수치 구분**: 공통 패턴(30% 이상), 반복 패턴(10%~30%), 특이 사례(10% 미만 중 우수 아이디어)
5. **공통점과 차이점 분석**: 대부분 사용 방식, 업종별 차이, 대립 방식, 고유 방식 파악
6. **장점과 문제점 분석**: 패턴 / 사용 홈페이지 / 장점 / 단점 / 어울리는 상황 / 주의할 점 정밀 작성
7. **최종 인사이트 3종 분류**: 반드시 참고할 공통 방식, 상황에 따라 선택할 방식, 차별화를 위한 독특한 방식 (근거 출처 연결)
8. **추가 조사 항목 표시**: 추측 배제하고 `추가 조사 필요 / 확인할 내용 / 현재 부족한 근거` 명시

## 🤖 7. AI 10단계 실행 수순 (Execution Steps)

1. 사용자의 분석 목적(홈페이지 레퍼런스 벤치마킹)을 확인한다.
2. 입력 폴더에 있는 자료 목록(`[리서치 결과]` 파일 및 추가 입력 자료)을 스캔한다.
3. 각각의 레퍼런스 자료를 읽는다.
4. 정해진 5대 기준(디자인 스타일, 화면 구성, 사용자 흐름, 문구와 콘텐츠, 주요 기능)으로 내용을 분류한다.
5. 중요한 내용마다 원문 위치(URL, Line)를 명확히 기록한다.
6. 자료들의 공통점과 차이점을 8단계 분석 방법론(30%/10% 패턴 수치)에 따라 산출한다.
7. 사실(Fact)과 AI의 해석(Interpretation)을 엄격히 구분한다.
8. 근거가 부족한 내용은 임의로 추측하지 않고 '추가 조사 필요' 항목으로 표시한다.
9. 정해진 포맷(100개 단위 분할 UTF-8 .txt 파일)으로 분석 보고서를 작성한다.
10. 결과를 최종 검사한다 (누적 데이터 덮어쓰기 여부 및 100개 제한 완결성 확인).
