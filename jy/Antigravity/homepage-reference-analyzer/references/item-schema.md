# 📄 개별 홈페이지 레퍼런스 분석 규격 (Item Schema)

모든 개별 홈페이지 레퍼런스는 아래 규격으로 개별 분석되어 텍스트 리포트에 기록됩니다.

---

### [개별 홈페이지 분석 포맷]

```markdown
■ [{번호}] {홈페이지 이름} ({URL})
- 디자인: [컬러 팔레트, 타이포그래피, 여백 비율, 비주얼 텍스처 특징]
- 화면 구성: [Hero 섹션 구도, 메인 레이아웃 순서, 그리드 시스템]
- 사용자 흐름: [스티키 GNB, 셰이드 퀴즈 탐색 동선, 퀵 장바구니 결제 동선]
- 문구와 콘텐츠: [핵심 캐치프레이즈, 정량적 임상 수치 카피, 브랜드 스토리텔링]
- 주요 기능: [Shade Matcher Genie, Before & After Dual Slider, 3D Object Viewer 등]
- 장점과 단점: [장점] ... / [단점] ...
- 참고할 부분: [새 홈페이지 기획 시 직접 벤치마킹할 핵심 요목]
```
