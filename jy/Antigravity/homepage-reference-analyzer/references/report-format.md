# 📄 홈페이지 레퍼런스 분석 출력 텍스트 표준 포맷 (Report Format)

본 포맷은 `homepage-reference-analyzer` 스킬 실행 시 자동 적용되는 UTF-8 `.txt` 출력 가이드입니다.

---

## 📌 출력 파일 분할 및 개수 규칙

- **파일 포맷**: UTF-8 암호화 `.txt` 텍스트 문서
- **한 파일당 제한**: 최대 100개 홈페이지 (1개 홈페이지 = 1개 분석 항목)
- **파일명 네이밍 규칙**: 
  - `리서치_분석_결과_001-100.txt`
  - `리서치_분석_결과_101-200.txt`
- **단일성 원칙**: 100번째 경계에 위치한 홈페이지의 개별 분석 내용은 절대로 파일 간 분할(Truncation)하지 않으며 완결된 형태로 포함함.

---

## 📑 TXT 파일 내부 구성 양식

```text
# 분석 결과 내용

1. 레퍼런스 수집 목록 (범위: 001-100)
- 홈페이지 이름: [브랜드명]
- URL: [웹사이트 주소]
- 업종: [뷰티/스킨케어/하이브리드 등]

2. 홈페이지별 분석
■ [001] [브랜드명] (https://example.com)
- 디자인: [컬러, 폰트, 여백, 비주얼 텍스처]
- 화면 구성: [Hero 섹션, 섹션 배치 순서, 그리드]
- 사용자 흐름: [GNB, 셰이드 탐색, Quick Cart 동선]
- 문구와 콘텐츠: [헤드라인, 임상 수치, 스토리텔링]
- 주요 기능: [Shade Matcher, Before/After Slider, 3D Viewer]
- 장점과 단점: [장점] ... / [단점] ...
- 참고할 부분: [핵심 벤치마킹 요소]

3. 전체 비교 분석
- 공통점: [85%+ 배경 톤 및 텍스처 초근접 연출]
- 차이점: [1-Step 루틴 강조 vs 셰이드 퀴즈 탐색 강조]
- 반복되는 패턴: [Hero 캐치프레이즈 + 임상 수치 배지]
- 눈에 띄는 사례: [Rose Inc 버블 모션, Muzigae Mansion 오브제 UI]

4. 최종 인사이트
- 새 홈페이지에 적용할 아이디어: [Soft Cream #FAF8F5 세팅, Shade Matcher Genie, Quick Slide Cart]
- 우선 참고할 홈페이지: [MERIT Beauty, Rhode Skin, Saie Beauty]
- 적용 시 주의할 점: [4K 초고화질 모바일 로딩 지연 최적화]
- 추가 조사가 필요한 내용: [3-in-1 용기 소재 선호도 및 셰이드 개수 A/B 테스트]
```
