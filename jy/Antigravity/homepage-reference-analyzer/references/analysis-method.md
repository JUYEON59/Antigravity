# 🧠 홈페이지 레퍼런스 8단계 분석 방법론 (Analysis Methodology)

본 문서는 수집 및 분류된 홈페이지 레퍼런스 자료를 정밀 심층 분석할 때 준수하는 **8단계 분석 절차 및 기준**입니다.

---

## 📌 8단계 분석 절차

### 1. 홈페이지별 개별 분석
각 홈페이지에서 다음 7가지 요소를 추출하여 개별 정리합니다 (4단계 분류 기준 적용).
- 디자인 특징
- 화면 구성
- 사용자 흐름
- 문구와 콘텐츠
- 주요 기능
- 장점과 단점
- 참고할 부분

### 2. 비슷한 내용 묶기
여러 홈페이지에서 비슷하게 나타나는 공통 요소들을 하나의 그룹으로 묶어 테마화합니다.
- 예: 큰 메인 캐치프레이즈 문구 사용, 마이크로 텍스처 수분 비주얼 사용, 스티키 상단 카트 버튼 배치, 고객 후기 제공 등

### 3. 등장 횟수 및 비율 확인
각 요소가 총 N개 홈페이지 중 몇 개에서 발견되었는지 수치화하고 비율(%)을 함께 기록합니다.
- 예: 스티키 카트 버튼 (160개 / 80%), 실물 피부 톤 Shade Matcher Genie (120개 / 60%)

### 4. 패턴 수치 기준 구분
- **공통 패턴**: 전체 홈페이지 중 **30% 이상** 채택
- **반복 패턴**: 전체 홈페이지 중 **10% 이상 30% 미만** 채택
- **특이 사례**: 전체 홈페이지 중 **10% 미만**이지만 참고 가치가 뛰어난 아이디어 (별도 기록)

### 5. 공통점과 차이점 찾기
- 대부분 사용하는 방식 (Consensus)
- 업종/서브 세그먼트에 따라 달라지는 방식
- 서로 반대되는 방식 (Contradictions & Trade-offs)
- 특정 홈페이지만 사용하는 고유 방식 (Unique Examples)

### 6. 장점과 문제점 분석
각 패턴에 대해 아래 규격으로 정밀 분석을 수행합니다.
```text
패턴명: [패턴 제목]
사용한 홈페이지: [브랜드명 / URL 출처]
장점: [사용 시 이점 및 UX 효과]
단점: [발생 가능한 리스크]
어울리는 상황: [적합한 세그먼트 및 브랜드 타입]
주의할 점: [구현 시 주의사항 및 최적화 요소]
```

### 7. 최종 인사이트 분류 & 근거 연결
분석 결과를 아래 3가지 카테고리로 구분하고, 근거가 된 홈페이지와 출처(URL, Line)를 명확히 연결합니다.
1. **반드시 참고할 공통 방식**
2. **상황에 따라 선택할 방식**
3. **차별화를 위해 참고할 독특한 방식**

### 8. 추가 조사 항목 표시
자료만으로 판단하기 어려운 내용은 추측을 배제하고 아래 서식으로 명시합니다.
```text
추가 조사 필요: [질문 주제]
확인할 내용: [검증할 구체적 항목 / A/B 테스트 과제]
현재 부족한 근거: [자료상 데이터가 부재한 이유]
```
