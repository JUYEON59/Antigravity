# 의뢰 메모 예시 3 — 청년 맞춤형 취업지원 서비스

## 기본 정보

- 의뢰 기관: 수업용 가상 청년지원기관
- 담당 부서: 일자리지원팀
- 프로젝트: 데이터 기반 청년 취업지원 서비스 개선
- 주요 대상: 취업 준비 초기 단계의 지역 청년

## 요청 배경

현재 취업 프로그램은 동일한 교육을 일괄 제공해 참여자의 전공, 경험, 희망 직무 차이를 충분히 반영하지 못한다. 상담, 역량 진단, 교육 추천, 구직 활동 기록을 연결한 맞춤형 지원 방식을 검토한다.

## 의뢰 목적

1. 청년 구직자의 서비스 이용 과정과 주요 이탈 원인을 조사한다.
2. 개인별 필요에 따라 상담과 교육을 연결할 수 있는 서비스 모델을 제안한다.
3. 기관 담당자가 운영할 수 있는 단계별 실행 계획과 역할을 설계한다.
4. 단순 참여 인원 대신 과정 지속률, 취업 준비 행동, 만족도 등을 평가할 KPI를 정한다.

## 제약 조건

- 참여자의 민감한 개인정보와 상담 기록을 최소한으로 수집한다.
- 자동 추천 결과만으로 교육이나 지원 대상자를 배제하지 않는다.
- 취업률 수치는 대상, 기간, 계산 기준을 명확히 표시한다.
- 기존 행정 시스템과의 연동 가능 여부는 아직 확인되지 않았다.
- 채용 결과를 프로그램 효과만으로 단정하지 않고 외부 요인을 함께 고려한다.

## 원하는 결과물

- 청년 취업지원 환경과 사용자 문제 리서치
- 개인화·데이터 활용·공정성 관련 트렌드 분석
- 서비스 흐름, 운영 역할, 개인정보 보호, KPI가 포함된 제안서
- 기관장과 실무자 대상 발표 자료

## 미확정 항목

- 대상 연령과 모집 규모
- 연계 교육기관
- 데이터 수집 항목
- 시스템 개발 범위
- 운영 예산과 일정
