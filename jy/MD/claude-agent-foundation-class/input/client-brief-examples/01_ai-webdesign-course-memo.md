# 의뢰 메모 예시 1 — AI 웹디자인 실무 교육과정

## 기본 정보

- 의뢰 기관: 수업용 가상 직업교육기관
- 담당 부서: 교육기획팀
- 프로젝트: AI 기반 웹디자인 실무 과정 신규 기획
- 주요 대상: 웹디자인 취업 준비생과 재직 디자이너

## 요청 배경

생성형 AI를 웹디자인 업무에 적용하려는 수요가 늘고 있지만, 기존 과정은 도구 소개에 머무는 경우가 많다. 조사, 아이디어 발상, UI 제작, 프로토타이핑, 결과물 검수까지 하나의 실무 프로젝트로 연결되는 신규 과정을 검토한다.

## 의뢰 목적

1. AI가 웹디자인 직무와 교육 수요에 미치는 변화를 근거 자료로 파악한다.
2. 취업 준비생과 재직자에게 필요한 AI 활용 역량을 정의한다.
3. 기존 웹디자인 과정과 차별화된 커리큘럼과 실습 프로젝트를 제안한다.
4. 교육 성과를 평가할 수 있는 포트폴리오 기준과 KPI를 설계한다.

## 제약 조건

- 총 교육 시간, 수강료, 개발 예산은 아직 확정되지 않았다.
- 특정 유료 AI 서비스 구매를 필수 조건으로 두지 않는다.
- 시장 규모와 취업 관련 수치는 검증 가능한 최신 자료만 사용한다.
- 저작권, 개인정보, 결과물 오류 검수 절차를 커리큘럼에 포함한다.
- AI가 만든 결과물을 그대로 제출하는 방식이 아니라 학습자의 판단과 수정 과정을 평가한다.

## 원하는 결과물

- 시장·교육 수요 리서치
- 핵심 트렌드와 기회·위험 분석
- 과정 목표, 커리큘럼, 일정, 필요 자원, KPI가 포함된 제안서
- 의사결정자 대상 15분 발표 자료

## 미확정 항목

- 총 교육 시간
- 사용할 AI·디자인 도구
- 강사 구성
- 개강 목표일
- 교육비와 개발비
