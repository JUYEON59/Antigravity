# 참고 자료 넣는 곳

교사가 제공한 PDF, 이미지, 기존 보고서, URL 목록 등을 이 폴더에 넣습니다.

## 권장 방식

- 파일 이름에 내용과 연도를 표시합니다. 예: `고용동향_2025.pdf`
- 웹 링크는 `reference-links.md`를 만들어 제목, 기관, URL, 확인일을 적습니다.
- 저작권이 있는 원문 전체를 불필요하게 복제하지 않습니다.
- 개인정보나 기관 기밀이 포함된 자료는 수업용 익명 자료로 교체합니다.

## 자료 우선순위

1. 정부·공공기관·표준기관의 원문
2. 기업의 공식 보고서와 제품 문서
3. 학술 논문과 전문 연구기관 보고서
4. 신뢰할 수 있는 언론 기사
5. 블로그, 커뮤니티, 홍보성 콘텐츠

하위 자료는 아이디어 탐색에 사용할 수 있지만 핵심 수치의 단독 근거로 사용하지 않습니다.
