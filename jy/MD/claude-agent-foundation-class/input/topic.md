# 프로젝트 주제

## 주제

2026년 AI 기반 웹디자인 교육 트렌드를 조사하고, 실무자 대상 신규 교육과정을 제안하는 발표 자료를 제작한다.

## 핵심 질문

1. AI가 웹디자인 실무와 교육 수요를 어떻게 바꾸고 있는가?
2. 학습자가 실제 업무에 적용하려면 어떤 역량과 도구를 배워야 하는가?
3. 기존 교육과 차별화할 수 있는 과정 구성은 무엇인가?
4. 제안 과정의 성과를 어떻게 측정할 수 있는가?

## 조사 범위

- 기준 지역: 대한민국 중심, 필요 시 해외 선도 사례 포함
- 기준 시점: 2024년 이후 자료 우선
- 주요 대상: 웹디자이너, UI/UX 디자이너, 비전공 취업 준비생, 재직자
- 포함 영역: 생성형 AI, 디자인 자동화, 프로토타이핑, 프론트엔드 협업, 저작권·윤리
- 제외 영역: 순수 모델 개발, 고급 데이터 엔지니어링

## 원하는 최종 결과

- 근거가 명시된 리서치 보고서
- 기회와 위험이 포함된 트렌드 분석
- 실행 일정과 KPI가 있는 교육과정 제안서
- 15장 안팎의 발표용 PPT

## 수업용 교체 방법

위 예시를 삭제하고 학생이 선택한 주제, 질문, 범위, 최종 결과를 작성합니다. 범위가 넓으면 지역·기간·대상·포함 영역을 먼저 좁힙니다.
