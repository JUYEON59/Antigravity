## 감점이 필요한 중대 오류

- 존재하지 않는 출처, 인용, 수치 사용
- 승인되지 않은 단계를 임의로 건너뜀
- 이전 산출물 삭제 또는 무단 덮어쓰기
- 텍스트 파일의 확장자만 바꾼 가짜 `.pptx`
- 개인정보나 기밀 정보의 부적절한 포함

중대 오류는 해당 영역을 `보완 필요`로 판정하고 수정 후 재평가합니다.

## 선택 심화 가산 피드백

점수 합계는 100점을 유지하되 다음 항목은 `워크플로 관리` 영역의 질적 피드백에 반영합니다.

- 팀원이 실제로 메시지를 교환하고 반론했는가?
- 합의와 이견을 모두 보존했는가?
- 에이전트가 기존 결과물을 무단 수정하지 않았는가?
- 최종 결정권이 사용자에게 남아 있는가?
