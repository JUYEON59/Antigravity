# KPI와 근거 추적 기준

## KPI 필수 요소

| 요소 | 질문 |
|---|---|
| 정의 | 정확히 무엇을 측정하는가? |
| 기준값 | 시작 시점의 값은 무엇인가? |
| 목표값 | 어느 수준을 언제까지 달성하는가? |
| 계산식 | 분자, 분모, 단위가 명확한가? |
| 주기 | 언제 측정하고 검토하는가? |
| 데이터 | 어떤 시스템이나 조사에서 얻는가? |
| 담당 | 누가 수집하고 판단하는가? |

기준값이 없으면 숫자를 만들지 말고 `사전 측정 필요`라고 씁니다. 목표값은 근거가 있거나 사용자와 합의된 경우에만 확정합니다.

## 선행·결과 지표

- **선행 지표**: 실행이 제대로 진행되는지 빠르게 보여 주는 지표. 예: 참여율, 과제 완료율.
- **결과 지표**: 최종 변화가 생겼는지 보여 주는 지표. 예: 업무 시간 변화, 전환율, 취업률.

가능하면 두 종류를 함께 사용합니다.

## 근거 추적표

각 제안은 다음 연결을 최소 하나 가져야 합니다.

```text
리서치 사실·출처 → 트렌드 해석 → 문제 → 제안 → KPI
```

연결이 끊기면 다음 중 하나로 처리합니다.

- 근거 추가 조사
- 제안 범위 축소
- 가정으로 표시하고 검증 계획 추가
- 제안에서 제외

## 위험 우선순위

발생 가능성과 영향도를 각각 상·중·하로 판단합니다. 둘 다 높은 위험은 실행 전에 예방책, 책임자, 중단 조건을 정합니다.
