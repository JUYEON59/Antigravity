# 트렌드 분류와 점수 기준

각 항목을 1~5점으로 평가하되 점수 근거를 한 문장으로 작성합니다. 점수는 비교를 돕는 도구이며 미래를 보장하지 않습니다.

| 기준 | 1점 | 3점 | 5점 |
|---|---|---|---|
| 변화 규모 | 일부 사례 | 여러 집단에서 관찰 | 산업 구조를 바꿀 가능성 |
| 변화 속도 | 정체 또는 감소 | 점진적 확산 | 짧은 기간에 빠른 확산 |
| 영향 범위 | 좁은 세부 영역 | 복수 직무·시장 | 산업 전반 또는 다산업 |
| 지속 가능성 | 이벤트성 | 조건부 지속 | 제도·비용·행동 변화로 고착 |
| 활용 가능성 | 적용 조건 불명 | 제한적 실험 가능 | 현재 자원으로 실행 가능 |
| 위험 수준 | 영향과 가능성 낮음 | 관리 필요 | 심각하며 즉시 대응 필요 |

## 신호와 트렌드 구분

- **신호**: 새 변화의 징후인 개별 사건, 사례, 지표.
- **패턴**: 서로 다른 자료에서 반복되는 유사 신호.
- **트렌드**: 일정 기간 지속되고 여러 대상에 영향을 주는 변화 방향.
- **구조적 변화**: 비용, 제도, 기술, 행동 방식이 함께 바뀌어 되돌리기 어려운 변화.

## 시간 범위

- 단기: 약 6~12개월
- 중기: 약 1~3년
- 장기: 3년 이상

주제의 변화 속도가 다르면 기간을 조정하고 그 이유를 기록합니다.

## 우선순위 판단

활용 가능성과 영향이 높으면서 대응 시급성이 큰 트렌드를 우선합니다. 위험 수준이 높은 항목은 기회 점수가 높더라도 안전장치와 중단 조건을 함께 제안합니다.
