# 출처 품질과 표기 기준

## 자료 우선순위

1. 법령, 정부, 공공기관, 국제기구, 표준기관 원문
2. 원 연구 논문, 공식 통계, 조사 방법이 공개된 보고서
3. 기업 공식 제품 문서, 공시, 기술 보고서
4. 전문 연구기관과 신뢰할 수 있는 언론의 분석
5. 블로그, 커뮤니티, 홍보 콘텐츠

핵심 수치와 시장 판단은 가능한 한 1~3순위 자료로 뒷받침한다. 4~5순위 자료는 사례 탐색이나 보조 설명에 제한적으로 사용한다.

## 확인 항목

| 항목 | 확인 질문 |
|---|---|
| 발행 주체 | 책임 있는 기관이나 저자가 명확한가? |
| 원문성 | 다른 글의 재인용이 아닌 원 자료인가? |
| 최신성 | 주제의 변화 속도에 맞는 시점인가? |
| 방법 | 표본, 지역, 기간, 계산 방식이 공개되어 있는가? |
| 관련성 | 조사 질문과 직접 관련되는가? |
| 독립성 | 판매나 홍보 목적이 결론을 왜곡할 가능성이 있는가? |
| 재현성 | 다른 사람이 링크나 파일로 다시 확인할 수 있는가? |

## 출처 번호

- 보고서에서 처음 등장한 순서대로 `S01`, `S02`처럼 부여한다.
- 같은 자료를 다시 사용할 때 같은 번호를 유지한다.
- 2차 자료가 원 연구를 인용하면 가능한 경우 원 연구를 출처로 사용한다.

## 출처 표 필수 정보

- 자료명
- 발행 기관 또는 저자
- 발행일 또는 연도
- 직접 URL 또는 프로젝트 내부 파일 경로
- 확인일
- 1차·2차 자료 구분

## 확신 수준

- **높음**: 최신 1차 자료가 있고 독립 근거가 일치한다.
- **중간**: 신뢰할 수 있는 근거가 있으나 범위나 시점에 제한이 있다.
- **낮음**: 사례 수가 적거나 2차 자료 중심이며 추가 검증이 필요하다.
