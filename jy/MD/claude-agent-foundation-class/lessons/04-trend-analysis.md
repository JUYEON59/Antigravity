# 4차시 — 변화 신호에서 트렌드 도출

## 학습 목표

- 리서치와 트렌드 분석의 차이를 설명한다.
- 단일 사례, 변화 신호, 반복 패턴, 구조적 트렌드를 구분한다.
- 변화의 원인과 영향, 기회와 위험을 분석한다.
- 모든 해석을 리서치 근거에 연결한다.

## 핵심 질문

```text
리서치: 무엇이 확인되었는가?
트렌드 분석: 여러 사실이 어떤 변화 방향을 보여 주며, 왜 중요한가?
```

## 시작 전 게이트

`output/workflow-status.md`에서 리서치가 `approved`인지 확인합니다. 승인되지 않았다면 Skill이 중단되는 것이 정상입니다.

## 실행

```text
/trend-analysis output/01_research/research-report.md를 분석해줘
```

## 분석 읽기

각 트렌드에 대해 다음을 확인합니다.

1. 이름이 변화 방향을 설명하는가?
2. 둘 이상의 근거가 있는가?
3. 발생 원인과 단순 동시 발생을 구분했는가?
4. 영향을 받는 대상과 시간이 명확한가?
5. 반대 신호나 불확실성이 있는가?
6. 기회뿐 아니라 위험도 적었는가?

## 점수 해석

`trend-scoring.md`의 1~5점은 트렌드를 서로 비교하기 위한 기준입니다. 소수점까지 정밀하게 계산하거나 점수를 미래 확률처럼 표현하지 않습니다.

## 수정 요청 예시

```text
트렌드 2는 단일 기업 사례에 지나치게 의존해. 신호 수준으로 낮추거나 추가 근거 필요로 표시해줘.
각 트렌드에 반대 신호를 한 개 이상 검토해줘.
단기 변화와 1~3년 중기 변화를 분리해줘.
제안서에 우선 반영할 트렌드 선정 이유를 더 명확히 해줘.
```

## 승인

```text
트렌드 분석 결과를 승인해. output/workflow-status.md에 반영해줘.
```

## 완료 기준

- [ ] `trend-analysis.md`가 있다.
- [ ] 모든 트렌드가 리서치 근거에 연결된다.
- [ ] 사례 나열을 변화 해석과 구분했다.
- [ ] 단기와 중장기를 구분했다.
- [ ] 기회, 위험, 반대 신호가 있다.
