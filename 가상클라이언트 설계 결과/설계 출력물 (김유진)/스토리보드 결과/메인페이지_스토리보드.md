## 📋 1. 스토리보드 개요

| 항목 | 세부 내용 |
|:---|:---|
| **프로젝트명** | NUNID(누니드) D2C 하이브리드 뷰티 커머스 메인페이지 스토리보드 |
| **발주자 / 브랜드** | NUNID (누니드) / 김유진 (NUNID 브랜드 기획 책임자) |
| **대상 화면 범위** | `SCR-010 메인 홈 (Main Page)` 전체 섹션 및 직결 핵심 오버레이 (`SCR-011 Quick Spec & Buy 모달`, `SCR-061 Sticky Quick Cart 드로어`) |
| **핵심 타깃 페르소나** | • **페르소나 A (김민지, 29세 / IT 마케터)**: 바쁜 출근 시간 단축을 위해 복잡한 메이크업 대신 스킨케어 결합 3-Step 하이브리드 루틴 선호, 이원화 CTA에서 '루틴 시작하기' 즉시 탐색<br>• **페르소나 B (이서연, 23세 / 대학생)**: 2만~5만 원대 합리적 투명 가격 선호, 5대 단일 뎁스 카테고리 탭 탐색, Quick Spec 모달로 상세 이동 없이 원클릭 빠른 결제 추구 |
| **핵심 설계 원칙** | ① 스킨케어·메이크업 하이브리드 3-Step 루틴 프로세스 바 제공<br>② 이원화 CTA 지원 (메인: 루틴 시작하기 / 보조: 제품 둘러보기)<br>③ 5개 단일 뎁스 카테고리 탭 (SUN/FACE/CHEEK/LIP/SET) 비동기 필터링<br>④ 3초 퀵스펙 모달 (0.02mm 극박 밀착, 24hr 지속, 2~5만원대 가격 노출)<br>⑤ 화면 이동 없는 상시 접근 Quick Cart 드로어 및 1분 Fast Checkout 직결 |
| **스토리보드 구조** | 공통 헤더, 6대 본문 섹션, 푸터, 2대 직결 오버레이(모달/드로어) 등 총 10개 단위 1:1 상세 명세 표 |

### [표 1] SEC-010-HDR : Global Fixed Header (공통 전역 상단 고정 헤더)

| 명세 항목 | 세부 설계 내용 |
|:---|:---|
| **화면/섹션 ID** | `SEC-010-HDR` (Global Fixed Header) |
| **섹션 명칭** | 공통 전역 상단 고정 헤더 |
| **화면 목적 & 사용자 목표** | 브랜드 아이덴티티 전달, 주요 4대 GNB 메뉴(ROUTINE, SHOP, BRAND, EVENT) 직결 이동 및 페이지 이동 없이 장바구니 수량과 배송조회를 상시 확인 |
| **와이어프레임 레이아웃** | ```text
+--------------------------------------------------------------------------------------------------------+
| [ ROUTINE ]  [ SHOP ]  [ BRAND ]  [ EVENT ]           [ NUNID ] (정중앙)          [ 주문조회 ]  [ 장바구니 3 ] |
+--------------------------------------------------------------------------------------------------------+
``` |
| **주요 콘텐츠 & 표시 데이터** | • **GNB 메뉴 4종 (좌측)**: `ROUTINE` (SCR-020 대표 뷰티 루틴 가이드), `SHOP` (SCR-030 전 제품 카테고리), `BRAND` (SCR-050 브랜드 소개 및 철학), `EVENT` (SCR-070 혜택 & 이벤트)<br>• **브랜드 로고 (정중앙)**: `NUNID` (상단바 정중앙 배치, 블랙 텍스트 볼드 16px, 클릭 시 최상단 복귀)<br>• **유틸리티 (우측)**: `주문조회` (비회원 배송조회 SCR-081 직결 버튼), `장바구니` (Quick Cart 드로어 SCR-061 토글 + 실시간 카운트 배지 `3`) |
| **인터페이스 & 작동 방식** | • **`ROUTINE` 클릭**: `SCR-020 대표 뷰티 루틴 3-Step` 섹션/페이지 이동<br>• **`SHOP` 클릭**: `SCR-030 5대 카테고리 제품 탐색` 섹션/페이지 이동<br>• **`BRAND` 클릭**: `SCR-050 브랜드 철학 및 스토리` 섹션/페이지 이동<br>• **`EVENT` 클릭**: `SCR-070 안심 무료 체험 및 프로모션` 섹션/페이지 이동<br>• **중앙 로고 클릭**: 메인 최상단으로 스크롤 복귀<br>• **`주문조회` 클릭**: `SCR-081 비회원 주문/배송 조회` 페이지 이동<br>• **`장바구니` 클릭**: 화면 이동 없이 우측에서 `SCR-061 Sticky Quick Cart 드로어` 슬라이드 오픈 |
| **연결 화면 (Next Screens)** | `SCR-010`, `SCR-020`, `SCR-030`, `SCR-050`, `SCR-070`, `SCR-061`, `SCR-081` |
| **상태별 처리 (States)** | • **기본 (Default)**: 상단 고정 (`position: sticky; top: 0; z-index: 50; background: #ffffff`)<br>• **스크롤 시**: 하단 1px 보더(`#e5e5e5`) 활성화<br>• **로고 정중앙 정렬**: 좌우 요소 너비와 무관하게 `left: 50%; transform: translateX(-50%)`로 완벽한 센터링 유지<br>• **카트 배지 0개**: 기본 텍스트 유지, 1개 이상 시 카운트 수치 노출 |
| **웹 접근성 (A11y)** | `<header>`, `<nav>` 시맨틱 태그 적용, 카트 버튼에 `aria-label="장바구니 열기, 담긴 상품 3개"` 제공, 키보드 Tab 포커스 링 지원 |
| **비고 및 정책** | 모바일 뷰포트(767px 이하)에서는 로고, 주문조회, 장바구니 버튼이 유지되며 GNB 메뉴는 모바일 네비게이션 형태로 유연하게 축소 전환 |

### [표 2] SEC-010-01 : 1.1 Hero Section (메인 히어로 & 이원화 CTA)

| 명세 항목 | 세부 설계 내용 |
|:---|:---|
| **화면/섹션 ID** | `SEC-010-01` (Hero Section) |
| **섹션 명칭** | 메인 비주얼 및 이원화 CTA 섹션 |
| **화면 목적 & 사용자 목표** | 내 피부에 필요한 것만 남긴 3-Step 루틴 가치를 3초 내 직관 전달하고, 사용자의 탐색 목적에 따라 루틴 또는 제품으로 즉시 분기 |
| **와이어프레임 레이아웃** | ```text
+--------------------------------------------------------------------------------------------------------+
| [HYBRID BEAUTY ROUTINE]                                                                                 |
| 내 피부에 필요한 것만 남긴 루틴, 누니드                    +------------------------------------------+ |
| 바쁜 아침, 여러 단계 겹쳐 바르지 마세요.                      | [초근접 제형 텍스처 & 3-Step 키 비주얼 컷] | |
| 피부 본연의 맑은 결을 살리는 3-Step 완성 하이브리드 루틴      | (Water-light / Velvet Tone / Melting)    | |
|                                                              |                                          | |
| [NUNID 루틴 시작하기 (메인 CTA)]  [전 제품 둘러보기 (보조 CTA)]                                        |
+--------------------------------------------------------------------------------------------------------+
``` |
| **주요 콘텐츠 & 표시 데이터** | • **카테고리 뱃지**: `HYBRID BEAUTY ROUTINE` (볼드 11px)<br>• **메인 헤드라인**: `내 피부에 필요한 것만 남긴 루틴, 누니드` (볼드 28px)<br>• **서브 카피**: `바쁜 아침, 여러 단계 겹쳐 바르지 마세요. 피부 본연의 맑은 결을 살리는 3-Step 완성 하이브리드 루틴`<br>• **메인 CTA 버튼**: `[NUNID 루틴 시작하기]` (솔리드 블랙 버튼, 볼드 13px)<br>• **보조 CTA 버튼**: `[전 제품 둘러보기]` (화이트 아웃라인 버튼, 볼드 13px)<br>• **우측 키 비주얼**: 초근접 제형 텍스처 & 3-Step 루틴 키 비주얼 매크로 컷 플레이스홀더 |
| **인터페이스 & 작동 방식** | • **`[✨ NUNID 루틴 시작하기]` 클릭**: 하단 `SEC-010-03 Signature Routine` 섹션으로 부드러운 앵커 스크롤(`smooth scroll`) 이동<br>• **`[🛍️ 제품 둘러보기]` 클릭**: 하단 `SEC-010-05 Category Grid` 섹션으로 부드러운 앵커 스크롤 이동<br>• **우측 비주얼 클릭**: `SCR-040 제형 & 원칙 랩`으로 이동 |
| **연결 화면 (Next Screens)** | `SEC-010-03` (루틴 섹션 앵커), `SEC-010-05` (카테고리 섹션 앵커), `SCR-040` (제형 랩) |
| **상태별 처리 (States)** | 데스크톱 2열 그리드(좌측 카피 1.2fr + 우측 비주얼 1fr), 모바일 수직 1열 배치 (버튼 가로 너비 100% 확장) |
| **웹 접근성 (A11y)** | 메인 헤드라인에 `<h1>` 태그 적용, 이미지 플레이스홀더에 `alt="스킨케어 메이크업 결합 하이브리드 제형 비주얼"` 제공 |
| **비고 및 정책** | 클라이언트 요구사항인 '이원화 CTA 구조'를 명확히 구현하여 탐색 중심 사용자와 구매 중심 사용자의 이탈을 방지 |

### [표 3] SEC-010-02 : 1.2 Problem & Solution Section (단계 축소의 힘 인포그래픽)

| 명세 항목 | 세부 설계 내용 |
|:---|:---|
| **화면/섹션 ID** | `SEC-010-02` (Problem & Solution Section) |
| **섹션 명칭** | 문제점 정의 및 3단계 축소 솔루션 비교 섹션 |
| **화면 목적 & 사용자 목표** | 10단계 복잡한 화장대의 피로감을 환기하고, 스킨케어와 메이크업을 결합한 3단계 미니멀 케어의 차별화된 가치 전달 |
| **와이어프레임 레이아웃** | ```text
+--------------------------------------------------------------------------------------------------------+
| 💡 WHY NUNID? 단계 축소의 힘                                                                            |
| 복잡한 10단계 화장대의 피로감 ➔ 스킨케어와 베이스를 결합한 [단 3단계 미니멀 케어]로 가볍고 투명한 피부 완성    |
| [기존: 토너-에센스-세럼-크림-선크림-프라이머-파데-컨실러-치크-립 10단계 피로감] vs [NUNID: 3-Step 완성]   |
+--------------------------------------------------------------------------------------------------------+
``` |
| **주요 콘텐츠 & 표시 데이터** | • **섹션 타이틀**: `💡 WHY NUNID? 단계 축소의 힘` (볼드 14px)<br>• **대비 설명 카피**: `복잡한 10단계 화장대의 피로감 ➔ 스킨케어와 베이스를 결합한 단 3단계 미니멀 케어로 가볍고 투명한 피부 완성`<br>• **비교 인포그래픽**: 10단계 레이어링(모공 막힘, 답답함) vs 3단계 하이브리드 케어(0.02mm 극박 밀착, 하루 종일 편안함) |
| **인터페이스 & 작동 방식** | 정적 인포그래픽 박스 (클릭 시 브랜드 철학 `SCR-050` 페이지로 상세 연결 링크 제공) |
| **연결 화면 (Next Screens)** | `SCR-050` (브랜드 철학) |
| **상태별 처리 (States)** | 클린 화이트 박스, 점선/실선 보더, 모바일 반응형 줄바꿈 최적화 |
| **비고 및 정책** | 타깃층(바쁜 직장인 및 대학생)의 Pain Point를 명확히 공략하는 콘텐츠 배치 |

### [표 4] SEC-010-03 : 1.3 Signature Routine Section (3-Step 프로세스 & 루틴 세트 구매)

| 명세 항목 | 세부 설계 내용 |
|:---|:---|
| **화면/섹션 ID** | `SEC-010-03` (Signature Routine Section) |
| **섹션 명칭** | 대표 3-Step 뷰티 루틴 프로세스 바 및 완성 세트 구매 배너 |
| **화면 목적 & 사용자 목표** | Step 1~3 순서대로 연결하여 본연의 결을 살리는 하이브리드 루틴을 시각화하고, 세트 특별 할인 혜택으로 일괄 구매 유도 |
| **와이어프레임 레이아웃** | ```text
+--------------------------------------------------------------------------------------------------------+
| 1.3 NUNID Signature 3-Step Routine                         [ 루틴 가이드 전체보기 (SCR-020) ➔ ]        |
| 단계별 순서대로 연결하여 결점 커버가 아닌 본연의 맑은 결을 정돈합니다.                                   |
|                                                                                                        |
| +--------------------------+  +--------------------------+  +--------------------------+               |
| | [STEP 1]                 |  | [STEP 2]                 |  | [STEP 3]                 |               |
| | [선베이스 50ml 컷]       |  | [톤업 플루이드 30ml 컷]  |  | [멜팅 립치크 15g 컷]     |               |

## ♿ 5. 웹 접근성 및 가정 사항 모음

### 5.1 웹 접근성 준수 지침 (A11y)
1. **명도 대비 4.5:1 이상 보장**: 화이트 배경 위의 다크 텍스트(`#0F172A`), Primary 블루 버튼(`#0284C7`)의 텍스트 대비를 7:1 이상의 고대비로 유지합니다.
2. **키보드 완전 탐색**: `Tab` 키로 헤더, 버튼, 카드, 모달, 드로어의 모든 상호작용 요소를 탐색할 수 있으며, 활성 요소에 `outline: 2px solid #0284C7` 포커스 링을 제공합니다.
3. **스크린 리더 완벽 지원**: 모든 이미지/제형 플레이스홀더에 `alt` 속성을 필수 적용하고, 모달/드로어에 `role="dialog"`, `aria-modal="true"`를 지정합니다.

### 5.2 가정 사항 모음 (`[가정]`)
1. `[가정: 비회원 중심 D2C]`: 최초 런칭 시점에는 회원가입 절차 없이 누구나 1분 내에 주문할 수 있는 비회원 초고속 결제를 기본 플로우로 정의하였습니다.
2. `[가정: 실시간 재고 연동]`: 특정 호수나 세트 품목의 재고 소진 시 실시간으로 품절 오버레이 및 입고 알림 신청 버튼으로 전환되는 백엔드 API 연동을 전제합니다.
3. `[가정: 100% 무료 반품 프로세스]`: 체험용 미니 샘플 테스트 후 피부 불만족 시 본품 미개봉 상태에서 원클릭으로 기사 방문 수거가 접수되는 자동 회수 시스템을 가정하였습니다.
