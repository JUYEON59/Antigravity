### [표 1] SEC-010-HDR : Global Fixed Header (공통 전역 상단 헤더)

| 명세 항목 | 세부 설계 내용 |
|:---|:---|
| **화면/섹션 ID** | `SEC-010-HDR` (Global Fixed Header) |
| **섹션 명칭** | 공통 전역 상단 고정 헤더 |
| **화면 목적 & 사용자 목표** | 브랜드 아이덴티티 전달, 주요 메뉴 직결 이동 및 페이지 이동 없이 장바구니 수량과 결제 상태를 상시 확인 |
| **와이어프레임 레이아웃** | ```text<br>+--------------------------------------------------------------------------------------------------------+<br>| [NUNID .]             [ All Hybrid ]      [ Formula & Proof ]      [ Philosophy ]    (주문조회)  [🛒 Cart 1] |<br>+--------------------------------------------------------------------------------------------------------+<br>``` |
| **주요 콘텐츠 & 표시 데이터** | • **브랜드 로고**: `NUNID .` (블랙 텍스트 볼드 18px, 마침표 포인트 블루 `#0284c7`)<br>• **GNB 메뉴 3종**: `All Hybrid`, `Formula & Proof`, `Philosophy`<br>• **유틸리티 링크**: `주문조회` (텍스트 링크 12px)<br>• **Quick Cart 버튼**: 카트 아이콘 + 실시간 담긴 품목 수 뱃지 (`Cart 1`) |
| **인터페이스 & 작동 방식** | • **로고 클릭**: 메인 최상단으로 부드러운 스크롤 복귀<br>• **`All Hybrid` 클릭**: `SCR-020 하이브리드 라인업` 페이지로 이동<br>• **`Formula & Proof` 클릭**: `SCR-030 데이터 검증 랩` 페이지로 이동<br>• **`Philosophy` 클릭**: `SCR-040 브랜드 철학` 페이지로 이동<br>• **`주문조회` 클릭**: `SCR-071 비회원 주문/배송 조회` 페이지로 이동<br>• **`[🛒 Cart N]` 클릭**: 페이지 새로고침 없이 우측에서 `SCR-051 Quick Slide Cart` 드로어 슬라이드 오픈 |
| **연결 화면 (Next Screens)** | `SCR-010`, `SCR-020`, `SCR-030`, `SCR-040`, `SCR-051`, `SCR-071` |
| **상태별 처리 (States)** | • **기본 (Default)**: 상단 고정 (`position: sticky; top: 0; z-index: 100`)<br>• **스크롤 중 (Scrolled)**: 배경 반투명 블러 (`backdrop-filter: blur(8px); background: rgba(255,255,255,0.95)`), 하단 1px 보더 활성화<br>• **카트 0개 (Empty Badge)**: 뱃지 회색 또는 숨김 처리 |
| **웹 접근성 (A11y)** | `<header>`, `<nav>` 시맨틱 태그 적용, 카트 버튼에 `aria-label="장바구니 열기, 담긴 상품 1개"` 제공 |
| **비고 및 정책** | 모바일 뷰포트(767px 이하)에서는 GNB 메뉴를 햄버거 드로어로 축소하고 로고와 카트 아이콘만 상단 고정 노출 |

| **인터페이스 & 작동 방식** | • **`[간편 뷰티 루틴 시작하기 ↓]` 클릭**: 하단 `SEC-010-02 제형 필터` 섹션으로 부드러운 스크롤(`scroll-behavior: smooth`) 이동 |
| **제한 조건 준수** | "별빛처럼...", "밤하늘을..." 등 추상적 카피 전면 배제 (100% 준수), 무거운 자동재생 비디오 배제 및 초경량 텍스처 컷 적용 |
| **상태별 처리 (States)** | 데스크톱 중앙 정렬 패딩 40px, 모바일 패딩 24px (폰트 크기 유연 반응) |
| **비고 및 정책** | 방문자가 랜딩 즉시 3초 내에 브랜드 컨셉과 가격대를 인지하도록 카피 명확화 |

### [표 3] SEC-010-02 : 1.2 Interactive Texture Filter (제형별 탭 필터)

| 명세 항목 | 세부 설계 내용 |
|:---|:---|
| **화면/섹션 ID** | `SEC-010-02` (Interactive Texture Filter) |
| **섹션 명칭** | 제형별 빠른 찾기 인터랙티브 탭 필터 |
| **화면 목적 & 사용자 목표** | 전통적인 스킨/로션/파운데이션 카테고리 분리 없이 제형(`Water-light`, `Melting Balm`, `Tinted Fluid`)을 1초 만에 스크리닝 |
| **와이어프레임 레이아웃** | ```text<br>제형별 빠른 찾기 (Interactive Texture Filter)  *전통 카테고리 분리 배제<br>[ 전체보기 (All) ]   ( Water-light )   ( Melting Balm )   ( Tinted Fluid )<br>``` |
| **주요 콘텐츠 & 표시 데이터** | • **섹션 타이틀**: `제형별 빠른 찾기 (Interactive Texture Filter)`<br>• **안내 문구**: `*전통 카테고리 분리 배제`<br>• **탭 1**: `전체보기 (All)` (기본 활성 상태)<br>• **탭 2**: `Water-light (워터라이트)` (수분 밀착 라인)<br>• **탭 3**: `Melting Balm (멜팅 밤)` (고보습 코팅 라인)<br>• **탭 4**: `Tinted Fluid (틴티드 플루이드)` (투명 톤업 라인) |
| **인터랙션 & 작동 방식** | • **탭 클릭 시**: 페이지 리로드 없이 하단 `SEC-010-03`의 제품 카드 그리드가 선택한 제형 데이터로 비동기 즉시 필터링<br>• 활성 탭: 다크 배경(`background: #0f172a; color: #ffffff`)으로 스타일 반전 전환 |
| **상태별 처리 (States)** | 모바일 화면에서는 가로 스크롤 스와이프 지원 (`overflow-x: auto; scrollbar-width: none;`) |
| **비고 및 정책** | 클라이언트 제한 조건 "전통적 카테고리 분리 금지" 반영 |

### [표 6] SEC-010-05 : 1.5 Real Reviews & 1.6 Trust Banner

| 명세 항목 | 세부 설계 내용 |
|:---|:---|
| **화면/섹션 ID** | `SEC-010-05` (Persona Reviews & Trust Banner) |
