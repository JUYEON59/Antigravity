## 1. 가상 클라이언트의 기본 정보 설정

- **프로젝트의 중심 주제**: 스킨케어와 메이크업을 자연스럽게 연결한 미니멀 하이브리드 뷰티 루틴 제안 및 D2C 웹사이트 메인페이지 설계
- **제작 목적**:
  - NUNID의 브랜드 철학(간결한 단계, 편안한 사용감, 피부 본연의 결을 살리는 자연스러운 표현)을 효과적으로 소개
  - 사용자가 복잡한 제품 탐색 없이도 브랜드의 문제 해결 방식과 대표 루틴을 즉시 이해하도록 유도
  - 대표 루틴 단계별 제품 정보 전달 및 개별 제품/루틴 세트의 직관적인 구매 전환(CTA) 달성
- **클라이언트 제공 자료**:
  - `가상클라이언트_김유진.pdf` (브랜드 브리프, 타깃 분석, 디자인 가이드라인, 필수 콘텐츠 10종, UI 구성요소, 제한 조건 등)
- **필요한 정보와 기능**:
  - **정보**: 브랜드 핵심 메시지, 기존 뷰티의 문제점 및 해결책, 대표 루틴(단계/역할), 제품별 제형·발림성·밀착감 시각 데이터, 카테고리별 제품 스펙(가격, 기능), 신뢰 정보
  - **기능**: 글로벌 내비게이션(GNB), 메인/보조 CTA 연결, 탭/스크롤 카테고리 필터, 루틴 단계 인터랙션 모듈, 제품 카드 요약 뷰, 간편 구매 전환 버튼
- **중요도와 작업 우선순위**:
  1. **최우선(High)**: 브랜드 문제 해결 메시지 + 대표 루틴 단계 UI + 히어로 제품 카드 + 직관적 제형 뷰 + 메인 CTA ("NUNID 루틴 시작하기")
  2. **보통(Medium)**: 카테고리별 빠른 탐색(SUN/FACE/CHEEK/LIP/SET) + 보조 CTA ("제품 둘러보기") + 브랜드 신뢰/제품 원칙 안내
  3. **후순위(Low)**: 푸터 영역 정책/기업 정보 및 보조 메뉴
- **적용 매체**: 반응형 웹 (데스크톱 및 모바일 최적화)

## 4. 비슷한 항목끼리 분류

1. **브랜드 아이덴티티 및 문제 해결 그룹 (Hero & Philosophy)**
   - 브랜드 핵심 가치 메시지 + 기존 복잡한 루틴의 문제점 + NUNID만의 하이브리드 솔루션
   - 자료 유형: 텍스트 헤드라인, 미니멀 그래픽 라인, 메인 CTA
2. **대표 루틴 및 사용 방식 그룹 (Signature Routine)**
   - 대표 제품 순서별 사용 단계(Step 1, Step 2, Step 3) + 단계별 역할 설명 + 루틴 세트(SET) 구매 연결
   - 자료 유형: 단계 표시 모듈형 UI, 제품 연계 이미지, 세트 구매 CTA
3. **제형 및 피부 표현 체험 그룹 (Texture & Skin Finish)**
   - 얇고 가벼운 밀착 제형 클로즈업 + 발림성 및 자연스러운 결 표현 시각화 + 제품 원칙
   - 자료 유형: 초근접 텍스처 이미지, 숏폼/GIF 그래픽 요소, 스펙 수치 인포그래픽
4. **카테고리 탐색 및 쇼핑 그룹 (Category & Product Grid)**
   - 5개 핵심 카테고리(SUN, FACE, CHEEK, LIP, SET) + 핵심 정보 중심의 제품 카드(가격 2~5만 원대 표기)
   - 자료 유형: 탭/필터 UI, 제품 카드 모듈, 상세페이지 링크/빠른 구매 버튼
5. **브랜드 신뢰 및 서비스 안내 그룹 (Trust & Footer)**
   - 3대 제품 원칙 + 사용자 안심 정보 + 기업 정보, 저작권, 고객 안내
   - 자료 유형: 텍스트 요약, 푸터 내비게이션 링크

## 5. 계층 구조 작성 (Information Architecture)

권장 기준(한 단계 메뉴 폭 5~9개 이내, 메뉴 깊이 3단계 이내)을 준수한 정보 구조도입니다.

```
NUNID D2C 메인페이지
├─ 1. Header (GNB)
│  ├─ Brand Logo (Home)
│  ├─ Navigation
│  │  ├─ Philosophy (브랜드 철학 & 문제 해결)
│  │  ├─ Routine (대표 루틴 3-Step)
│  │  ├─ Products (카테고리: SUN / FACE / CHEEK / LIP / SET)
│  │  └─ Proof & Texture (제형 & 제품 원칙)
│  └─ Utility (Search, Cart/Quick-Buy)
│
├─ 2. Main Visual (Hero)
│  ├─ Key Message ("스킨케어와 메이크업의 자연스러운 연결")
│  ├─ Visual Banner (투명하고 자연스러운 텍스처/일상 이미지)
│  └─ Primary / Secondary CTA ("루틴 시작하기" / "제품 둘러보기")
│
├─ 3. Problem & Solution
│  ├─ Pain Points (복잡한 단계, 피부 답답함, 선택 피로)
│  └─ NUNID Solution (단계 축소, 편안한 밀착, 자연스러운 결 표현)
│
├─ 4. Signature Routine (대표 루틴)
│  ├─ Step-by-Step UI (Step 1 ➔ Step 2 ➔ Step 3)
│  ├─ Hero Products (각 단계별 대표 제품 카드)
│  └─ Routine Set CTA (루틴 세트 바로 구매하기)
│
├─ 5. Texture & Proof (제형 & 표현)
│  ├─ Texture Close-up (초근접 제형 컷, 발림성 시각화)
│  └─ 3 Principles (간결한 단계, 편안한 사용감, 자연스러운 표현)
│
├─ 6. Category Exploration (카테고리별 제품)
│  ├─ Category Tab (SUN / FACE / CHEEK / LIP / SET)
│  └─ Product Grid (제품명, 카테고리, 제형, 가격, 구매 CTA)
│
└─ 7. Footer
   ├─ Company Info & CS
   ├─ Terms & Policies
   └─ Social Channels
```

## 7. 내비게이션으로 연결 (User Journey & Flow)

- **시작 화면**: 메인페이지 최상단 Hero 섹션 (브랜드 헤드라인과 직관적인 텍스처 비주얼)
- **사용자 핵심 이동 경로 (User Flow)**:
  - **경로 A (루틴 중심 탐색)**: Hero 메인 CTA ("NUNID 루틴 시작하기") 클릭 ➔ 대표 루틴 3-Step 섹션 스크롤 이동 ➔ 단계별 제품 확인 ➔ 루틴 세트(SET) 장바구니/구매
  - **경로 B (개별 제품 탐색)**: GNB 'Products' 또는 Hero 보조 CTA ("제품 둘러보기") 클릭 ➔ 카테고리 탭(SUN/FACE/CHEEK/LIP/SET) 선택 ➔ 제품 카드 요약 스펙(제형, 가격) 확인 ➔ 상세페이지 이동 또는 간편 구매
  - **경로 C (제형 및 신뢰 확인)**: GNB 'Texture & Proof' 클릭 ➔ 텍스처 클로즈업 및 3대 제품 원칙 확인 ➔ 적합한 제형 제품 탐색으로 연결
- **화면 전환 및 내비게이션 요소**:
  - **상단 고정 Sticky GNB**: 스크롤 중에도 언제든 주요 섹션 이동 및 장바구니 확인 가능
  - **스무스 앵커 스크롤**: 메인 CTA 클릭 시 메인페이지 내 대표 루틴 영역으로 부드럽게 화면 이동
  - **모달 / 간편 뷰**: 제품 카드에서 불필요한 긴 설명 없이 핵심 스펙(가격, 제형, 기능)을 즉시 확인
  - **반응형 햄버거 메뉴 (모바일)**: 모바일 환경에서 1뎁스 탭 구조로 빠른 전환 지원
